# Implementation and pattern coverage audit

Audit date: 2026-10-28. Scope: the current implementation, math, specialist, and worked-pattern handbooks, checked against the local 2017–2025 Latin American Regional research and primary contest materials. This is an editorial gap audit for preparation through November 8, not a prediction or an exhaustive reclassification of every problem.

## What is already covered

The useful beginner-to-intermediate foundation is substantially present. The implementation handbook teaches components, BFS and path recovery, multi-source and grid BFS, implicit/product states, 0-1 BFS, Dijkstra, DAG order, DSU/Kruskal, rooted tree order and binary-lifting LCA, compression, prefix/difference arrays, interval merge, windows, answer search, Fenwick/segment trees, knapsack, counting loop order, LIS, and digit-pattern DP with reconstruction. Its worked pages add parity-state BFS, moving hazards, remainder DP, strict-tie weighted dominance DP, small-subset toggle enumeration, and a slow-to-fast transition exercise. The math handbook adds exact arithmetic, modular/remainder reasoning, factorization and gcd classes, counting, expectation, and geometric predicates. The specialists handbook has concise APIs for SCC/2-SAT, matching/flow, selected tree paths, strings, geometry, line optimization, and matrix powers.

These are usable starting points, not just names in an index: the prose explains key state definitions, invariants, half-open range conventions, common failure cases, and code contracts. In particular, do not report small-subset enumeration, state-graph BFS, or static interval union as missing. A static interval-union helper and walkthrough were added after the older coverage audit.

## Preparation order through November 8

Use the remaining practice time to make the existing material automatic: BFS/shortest paths, components and DSU, topological order, basic tree traversal/LCA, simple Fenwick or segment-tree queries, and small DP state design with reconstruction. For math, prioritize exact values, remainders, counting, overflow bounds, and proving a greedy rule. Those skills unlock more of the accessible cases than attempting to memorize rerooting, dynamic sweeps, or advanced constructions.

If the team can already solve ordinary tree and DP exercises, add just two short cards: (1) Euler flattening for subtree intervals, because it composes directly with learned ranges; (2) `dp[mask][last]`, because it is a common, bounded pattern and gives a clean proof exercise. Keep offline threshold sweep as a worked extension for a teammate comfortable with Fenwick trees. Leave rerooting, tree-DP-plus-matching, the inversion unranking recurrence, and the connectivity-preserving cycle proof as recognition/reference material unless a full practice problem makes one immediately relevant.

The existing Mexico companion audit separately checked two Masters Mexico 2022 statements: F, *Flip*, is 512-mask exhaustive simulation; H, *Hidden Number*, is sorted-prefix subset-sum greedy. Both have since been added as worked patterns (see [Mexico/Masters audit](mexico-masters-round3.md)). The 2024 Final Regional listing says the contest was the LATAM regional hosted by Brazil with Mexican teams participating, so it should not be counted as an independent Mexico-only Finals problem set ([ICPC México event page](https://www.icpcmexico.org/contests/regional-mexico-2024)). Masters and repechaje are distinct practice sources; do not pool their problem counts with the regional corpus.

## Evidence limits

The existing regional atlas spans 116 problems over nine editions, but its labels overlap and have mixed evidence status; it is not an official topic taxonomy or a probability model. The repository's own corpus report records editorial-backed, other verified, and provisional classifications separately. The examples above establish that these patterns occurred, not their frequency or likelihood in the next event. Official statements confirm task requirements and bounds; official sketches/editorials support the attributed solution ideas. The 2025 C and some other atlas approaches are marked derived or unverified, so they are not presented here as accepted algorithms. This audit does not claim complete coverage of all years, all Mexico repechajes, all Masters contests, or every problem in the corpus.
