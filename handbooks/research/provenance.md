Prior selected checks included 109 released Fuzzy Factorization inputs, 32 Balanced Balloons inputs, and small cases for Displaying Decimals. Those results do not validate every new helper, nor establish full-constraint performance for the proposed Displaying Decimals aggregation. That specialist aggregation is intentionally excluded.

## What these books add

The existing KACTL is a compact specialist library. The companions add recognition, proof sketches, explicit preconditions, failure cases, and foundational helpers. KACTL source excerpts remain attributed to their original authors. New helper tests use naive or exhaustive independent oracles where practical. See VALIDATION.md for exact checks run on this edition.

Topic recurrence informed selection. It does not guarantee what will appear at the finals. Code that has only local tests is not labeled judge-accepted.
